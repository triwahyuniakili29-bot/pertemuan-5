Deskripsi Project
Project ini merupakan praktikum Java menggunakan Java I/O, NIO.2, dan Jackson untuk membuat sistem logging audit.

 Teknologi
- Java 17
- Maven
- Jackson Databind
- JavaTimeModule
- Java NIO.2

Fitur
- Menyimpan data log dalam format NDJSON.
- Membaca data log.
- Menghitung event berstatus error (>= 400).
- Mengabaikan baris log yang rusak.
